# Codex Mobile 安卓 0.2.36

Dot 语音新增后台与锁屏保持机制：通话期间启用系统前台语音服务和通话通知，可从通知返回 App 或挂断；挂断后释放音频、服务和唤醒锁。

## 使用方式

1. 先挂断现有通话，再覆盖安装新版，保留已有设备配置。
2. 在 App 内接通 Dot，首次使用时允许麦克风及通知权限。
3. 接通后可按 Home、切换应用或锁屏，不需要让屏幕一直亮着。
4. 结束时点击 App 或通知栏的挂断按钮。

系统强行停止、从任务列表移除 App 或连接中断会结束通话。本版不申请电池优化豁免；不同手机的后台限制仍以实测为准。
