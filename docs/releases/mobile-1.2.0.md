# Mobile 1.2.0

## 新增功能

- 原 Dots 对话页新增电话按钮，支持实时语音、计时、静音和挂断，通话时仍可查看原有消息。
- 沿用桌面登录账户建立通话，浏览器直接传输 WebRTC 音频。

## 连接与恢复

- 通话请求绑定账户和 Dot，创建请求不自动重发；结果未知时阻止重复拨号。
- 取消连接、切换 Dot 或设备、页面退出和网络中断时释放本地麦克风，并通过服务端租约清理通话。
- 旧通话的延迟响应不会覆盖新通话，网关退出时先挂断再释放桌面连接。

## 使用要求与验证

- 需要支持语音信令的 Launcher；随桌面版 0.2.0 提供，旧宿主不显示电话按钮。
- 浏览器需要安全上下文和麦克风权限；手机网页应通过可信 HTTPS 访问。
- 已通过受控 Chromium 双向音频测试，以及本机原对话页面连接真实 Dot、双向音频 RTP 和挂断验证。手机系统的权限、实体听说和后台行为仍以实际设备为准。

插件配置、账户和现有消息接口保持兼容。本次未包含独立的人工验收页面。
